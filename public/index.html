Manifest HQ requests private inference on 0G. According to 0G, the model runs inside a hardware-isolated enclave, and its Router retains usage metadata rather than prompts or responses.

A session, not a document libraryManifest HQ does not save your files or conversations as a persistent library.

What is stored?

Technical logs record request metadata, not document contents. The server processes readable document content and removes temporary PDF files after extraction. Private routing protects the inference step; manifest HQ does not independently verify hardware attestations. If Gemini fallback is enabled, document content and conversation context can also go to Google under its API terms. Google’s free tier may use content to improve its products.
