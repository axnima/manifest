A REAL REQUEST. A VISIBLE RESULT.
From documents to answers.

  
  1. Upload PDF, PNG/JPEG/WebP, text, CSV, JSON, DOCX, XLSX, PPTX, or ODT files. Other UTF-8 text files are also accepted. Unsupported binaries, encrypted documents, and older Office formats require conversion.
  2. Create a Gemini API key using a Free Tier project in Google AI Studio.
  3. Tell the assistant what to do. The app sends file content, your question, and recent chat context to Google.
  4. Gemini writes a complete React component. The local backend compiles its React JSX before rendering in an isolated preview. Follow-up messages revise the current dashboard.

  
The assistant selects summaries, metrics, tables, and charts to fit your request. It should distinguish facts, assumptions, and estimates. Model-generated calculations and source references need checking.

  
Nothing is stored by this app. Google receives the request and applies its own data policy. Your API key is held only in page memory; clear it or close the page when finished. For shared production use, move the key and inference calls to an authenticated backend.

  
Provider errors are shown explicitly. The app never substitutes a fake AI response or silently changes providers.
