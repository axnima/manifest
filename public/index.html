A REAL REQUEST. A VISIBLE RESULT.
From documents to answers.

  
  1. Upload text PDFs, text, CSV, JSON, DOCX, XLSX, PPTX, or ODT files. Images use model vision; scanned PDFs need conversion to images or text.
  2. Configure the local backend using the root .env file.
  3. Your document text, question, recent conversation, and previous component are sent through the backend to 0G using Private routing.
  4. 0G writes React. The backend compiles it and the browser renders an isolated preview. Follow-ups revise the dashboard.

  
Source references and calculations need checking. Original files and generated source are not persisted by the app; sanitized request metadata is logged locally. The local backend handles plaintext documents and source. Private routing is requested from 0G; it is not a claim that the entire app is end-to-end encrypted.

  
Provider errors are shown explicitly. The app never substitutes a fake AI response or silently changes providers.
