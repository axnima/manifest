From documents to dashboards

  1. Bring your files. Upload a report, spreadsheet, image, or text file. You can also try the fictional sample.
  2. Ask what you need. Request a summary, comparison, chart, or forecast. Relevant file contents and conversation context are sent to 0G with private routing requested.
  3. Refine the result. Your answer appears as an interactive dashboard. Ask a follow-up to change it, or inspect and export its React source.

AI can make mistakes. Check important figures and source references before relying on the result. Forecasts are estimates based on the available data and stated assumptions.

Supported files

Upload PDF, PNG, JPEG, WebP, CSV, JSON, DOCX, XLSX, PPTX, ODT, or other UTF-8 text files. Up to 5 files, 4 MB each, and 8 MB total. PDFs must contain selectable text and be no longer than 100 pages. Convert scanned PDFs to text or supported images first. Office formatting and embedded images are not preserved; spreadsheet formulas are not recalculated.

Privacy and storage

Files, chat, and generated dashboards are not saved between visits. Export the React source if you want to keep a copy. The server processes readable document content; PDF extraction uses temporary files that are removed afterward.

Technical logs record request IDs, timing, status, and usage where available. They exclude document contents, chat messages, API keys, and generated source. According to 0G, its Router also retains usage metadata rather than prompts or responses.

We request private inference without a fallback to a lower privacy tier. This protects the model’s inference step; it does not make the entire app end-to-end encrypted. Manifest HQ does not independently verify hardware attestations.

How the dashboard is generated

0G returns an explanation and React code. The server compiles the code, then your browser displays it in a sandboxed preview. If generation or compilation fails, you’ll see an error. No placeholder answer is substituted.
